這是一份為你量身打造的「Discord Activity 整合 Jitsi Meet 自動登入系統」完整技術企劃書。
本方案採用 Vercel 無伺服器架構（Serverless），實現以下核心目標：
1. 一鍵無縫進入：關閉 Jitsi Prejoin 頁面，點開 Activity 直接進入視訊室。
2. 強制實名制：自動抓取使用者的 Discord 伺服器暱稱並鎖定，防止隨意改名。
3. 亂碼防猜測房號 + 自訂會議標題：底層使用高強度亂碼作為 roomName（確保隱私與安全），但透過網址參數與界面覆寫，讓畫面上的會議標題依然顯示為人類可讀的「伺服器/頻道會議名稱」。

專案技術企劃書：Discord Activity x Jitsi Meet 專屬視訊橋接器


1. 系統架構與運作流程

由於 Discord Activity 運行在嚴格的沙盒（Iframe）與內容安全政策（CSP）中，本系統透過 Vercel 作為「安全橋接層」：
1. 啟動與授權：使用者在 Discord 語音頻道點擊啟動 Activity，載入託管於 Vercel 的前端網頁。
2. 身份交換：前端呼叫 @discord/embedded-app-sdk 取得臨時授權碼（code），並連同 guildId、channelId 傳送給 Vercel 後端（/api/session）。
3. 資料組裝：Vercel 後端使用 CLIENT_SECRET 向 Discord API 換取資料：
	• 取得使用者的伺服器暱稱（若無則退回全域顯示名稱）。
	• 取得伺服器名稱與語音頻道名稱，組合成可讀的會議標題（例如：技術部 - 每日站會）。
	• 根據 channelId 搭配後端秘密鹽值（Salt）產生一組不可逆的亂碼房號（例如：dc_a8f92b7e4c1d...），避免外人隨意猜測網址闖入。
4. 自動登入與界面覆寫：前端取得這些資訊後，透過 Jitsi IFrame API 載入會議室，跳過準備頁面直接登入，並將亂碼房號隱藏，替換為可讀的會議名稱。

3.3 api/session.js（後端 API：驗證、抓暱稱、生成亂碼房號）

這支程式在 Vercel 雲端執行，負責保護你的機密金鑰並組裝會議資訊：
javascript
import crypto from 'crypto';

export default async function handler(req, res) {
  if (req.method !== 'POST') {
    return res.status(405).json({ error: 'Method Not Allowed' });
  }

  const { code, guildId, channelId } = req.body;
  const CLIENT_ID = process.env.DISCORD_CLIENT_ID;
  const CLIENT_SECRET = process.env.DISCORD_CLIENT_SECRET;
  const ROOM_SECRET = process.env.ROOM_HASH_SECRET || 'default-secret-salt';

  try {
    // 1. 用前端傳來的 code 換取 Discord Access Token
    const tokenResponse = await fetch('https://discord.com', {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        client_id: CLIENT_ID,
        client_secret: CLIENT_SECRET,
        grant_type: 'authorization_code',
        code: code,
      }),
    });

    const tokenData = await tokenResponse.json();
    if (!tokenData.access_token) {
      throw new Error('無法取得 Access Token');
    }

    const authHeader = { Authorization: `Bearer ${tokenData.access_token}` };

    // 2. 平行請求：取得使用者資料、伺服器成員資料（含伺服器暱稱）
    const [userRes, memberRes] = await Promise.all([
      fetch('https://discord.com', { headers: authHeader }),
      guildId 
        ? fetch(`https://discord.com/guilds/${guildId}/member`, { headers: authHeader })
        : Promise.resolve(null)
    ]);

    const userData = await userRes.json();
    const memberData = memberRes && memberRes.ok ? await memberRes.json() : null;

    // 決定最終顯示名稱：優先使用伺服器暱稱 > 全域顯示名稱 > 帳號名稱
    const displayName = memberData?.nick || userData.global_name || userData.username;

    // 3. 產生安全的「亂碼房號」（同一個頻道永遠會算出同一組亂碼，外人無法反推）
    const hash = crypto
      .createHmac('sha256', ROOM_SECRET)
      .update(`${guildId || 'dm'}_${channelId}`)
      .digest('hex')
      .substring(0, 24); // 取前 24 碼作為亂碼房名
    
    const secureRoomId = `dc_${hash}`;

    // 4. 決定畫面上要顯示的「人類可讀會議名稱」
    // (註：若要自動抓取頻道名稱，需額外使用 Bot Token 呼叫 /channels/{id}，此處先提供預設格式)
    const readableMeetingTitle = `語音頻道專屬會議室`;

    return res.status(200).json({
      access_token: tokenData.access_token,
      displayName,
      secureRoomId,
      readableMeetingTitle
    });

  } catch (error) {
    console.error('Session Error:', error);
    return res.status(500).json({ error: error.message });
  }
}

3.4 public/index.html（前端網頁：自動登入、參數配置、隱藏亂碼）

這裡特別結合了 Jitsi Meet 的 URL Hash/Query 參數（#config... 與 #interfaceConfig...） 以及 External API 覆寫，確保即便底層房號是 dc_a8f92b... 亂碼，畫面左上角與瀏覽器分頁依然顯示為 語音頻道專屬會議室：

<html lang="zh-Hant">

  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />

  <style>
    body, html {

      width: 100%;
      height: 100%;
      overflow: hidden;
      background-color: #1e1f22; /* Discord 深色背景 */
      color: #ffffff;
      font-family: sans-serif;
    }
    #loading {
      display: flex;
      justify-content: center;
      align-items: center;
      height: 100%;
      font-size: 1.2rem;
    }
    #jitsi-container {
      width: 100%;
      height: 100%;
      display: none;
    }
  </style>
  <!-- 引入 Jitsi Meet External API (透過 Discord URL Mapping 路徑載入) -->

<body>
  <div id="loading">正在驗證 Discord 身份並自動進入會議室...</div>
  <div id="jitsi-container"></div>

  <script type="module">
    import { DiscordSDK } from "https://esm.sh";

    // 替換為你的 Discord Application Client ID
    const CLIENT_ID = "你的_DISCORD_CLIENT_ID"; 
    const discordSdk = new DiscordSDK(CLIENT_ID);

    async function startMeeting() {
      try {
        // 1. 等待 Discord 客戶端準備就緒
        await discordSdk.ready();

        // 2. 請求使用者授權（需要 identify 與 guilds.members.read 才能抓伺服器暱稱）
        const { code } = await discordSdk.commands.authorize({
          client_id: CLIENT_ID,
          response_type: "code",
          state: "",
          prompt: "none",
          scope: ["identify", "guilds.members.read"],
        });

        // 3. 呼叫 Vercel 後端換取資料與亂碼房號
        const response = await fetch("/api/session", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            code,
            guildId: discordSdk.guildId,
            channelId: discordSdk.channelId,
          }),
        });

        const sessionData = await response.json();
        if (!response.ok) throw new Error(sessionData.error);

        // 4. 完成 Discord SDK 客戶端驗證
        await discordSdk.commands.authenticate({
          access_token: sessionData.access_token,
        });

        // 隱藏載入畫面，顯示視訊容器
        document.getElementById("loading").style.display = "none";
        document.getElementById("jitsi-container").style.display = "block";

        // 5. 初始化 Jitsi Meet
        // 注意：domain 必須填寫當前網域並加上映射路徑，以符合 Discord CSP 規範
        const domain = window.location.host + "/jitsi";
        
        const options = {
          roomName: sessionData.secureRoomId, // 底層使用安全亂碼房號
          width: "100%",
          height: "100%",
          parentNode: document.querySelector("#jitsi-container"),
          userInfo: {
            displayName: sessionData.displayName // 自動帶入 Discord 伺服器暱稱
          },
          configOverwrite: {
            // 【關鍵 1】關閉加入前預覽頁，直接進入會議
            prejoinConfig: {
              enabled: false
            },
            // 【關鍵 2】覆寫會議室顯示標題，隱藏底層亂碼房號
            subject: sessionData.readableMeetingTitle,
            // 預設靜音進入，提升體驗
            startWithAudioMuted: true,
            startWithVideoMuted: false,
            // 關閉深層連結提示（避免跳出「請下載 Jitsi App」的干擾視窗）
            disableDeepLinking: true
          },
          interfaceConfigOverwrite: {
            // 隱藏右上角與左上角可能暴露真實亂碼網址的邀請與浮水印按鈕
            HIDE_INVITE_MORE_HEADER: true,
            SHOW_JITSI_WATERMARK: false,
            SHOW_WATERMARK_FOR_GUESTS: false
          }
        };

        const api = new JitsiMeetExternalAPI(domain, options);

        // 【關鍵 3】雙重保險：進入會議後再次透過指令強制設定會議標題，並鎖定使用者名稱
        api.addEventListeners({
          videoConferenceJoined: () => {
            api.executeCommand("subject", sessionData.readableMeetingTitle);
          },
          displayNameChange: (params) => {
            // 若使用者試圖手動改名，立刻強制改回 Discord 伺服器暱稱
            if (params.displayname !== sessionData.displayName) {
              api.executeCommand("displayName", sessionData.displayName);
            }
          }
        });

      } catch (err) {
        document.getElementById("loading").innerText = `啟動失敗：${err.message}`;
        console.error(err);
      }
    }

    startMeeting();
  </script>
</body>
</html>

4. 部署與後台設定步驟


步驟一：部署至 Vercel

1. 將上述四個檔案上傳至你的 GitHub 儲存庫。
2. 前往 Vercel 匯入該專案並點擊 Deploy。
3. 進入 Vercel 專案的 Settings -> Environment Variables，新增以下三個環境變數：
	• DISCORD_CLIENT_ID：你的 Discord 應用程式 ID
	• DISCORD_CLIENT_SECRET：你的 Discord 應用程式密鑰
	• ROOM_HASH_SECRET：隨意輸入一串複雜亂碼（用於加密生成房號）
4. 重新部署（Redeploy）一次讓環境變數生效，並記下 Vercel 分配給你的網址（例如 https://vercel.app）。

步驟二：設定 Discord Developer Portal

1. 前往 Discord Developer Portal 選擇你的應用程式。
2. 開啟 Activity 功能：
	• 在左側選單點擊 Activities -> Settings，將 Enable Activities 開關打開。
3. 設定 OAuth2 重新導向：
	• 在左側選單點擊 OAuth2，在 Redirects 欄位新增你的 Vercel 網址：https://vercel.app。
4. 設定 URL Mappings（最關鍵步驟）：
	• 在左側選單點擊 Activities -> URL Mappings。
	• 設定根路徑映射：Prefix 填 /，Target 填 my-jitsi-act.vercel.app。
	• 設定 Jitsi 代理映射：Prefix 填 /jitsi，Target 填你的 Jitsi 伺服器網域（例如 meet.jit.si 或你自架的 ://yourdomain.com）。

5. 關於 Jitsi URL 參數的補充說明

在實際運作時，Jitsi Meet 允許直接透過網址的 #（Hash）參數來控制行為。雖然上述程式碼已經透過 JitsiMeetExternalAPI 自動幫你將設定轉譯為底層 URL 參數，但如果你需要在特定情況下手動組合 Jitsi 網址，其對應的 URL 參數格式如下：
text
https://你的Jitsi網域/dc_a8f92b7e4c1d#config.prejoinConfig.enabled=false&config.subject="語音頻道專屬會議室"&userInfo.displayName="王小明"
請謹慎使用程式碼。
• config.prejoinConfig.enabled=false：強制跳過準備畫面直接登入。
• config.subject="自訂名稱"：即使網址路徑是 dc_a8f92b7e4c1d 亂碼，畫面上的會議標題依然會強制顯示為引號內的文字。
• userInfo.displayName="暱稱"：自動代入進入者的顯示名稱。

⚠️ 實務營運提醒

如果你使用的是官方免費的 meet.jit.si，因為官方伺服器有「第一位進入者必須登入 Google/GitHub 帳號（Lobby/Moderator 驗證）」的限制，自動登入會卡在要求第一位使用者登入的畫面。強烈建議搭配自架的 Jitsi Meet 伺服器（關閉強制登入驗證）或 JaaS 服務，才能達到 100% 點開即視訊的完美體驗。
如果你想讓會議標題直接顯示「真實的 Discord 頻道名稱」（例如自動抓出 #一般語音 而不是寫死的 語音頻道專屬會議室），需要我幫你在 api/session.js 中補上透過 Discord Bot Token 查詢頻道名稱的程式碼嗎？
